## 最重要的三条 · 初答（每条留修订位，踩到那天补一行）

### 1. 为什么阶段 1-2 不上向量库

- **决策**：使用关键词检索
- **代价**：关键词检索的准确率可能不如向量检索，可能造成更大的上下文浪费，效果也比较差。
- **什么时候可能推翻它**：关键词检索出现问题、想了多个方案仍无提升时。

### 2. 为什么从第一天就写类型标注（而不是"先跑通再说"）

- **决策**：使用 mypy 进行类型检查
- **代价**（review 修订，原答写成了优点）：初期写代码更慢；第三方库类型标注不全时被迫写 `str()` / `cast` 强转 —— `resp.content` 那次就是。
- **什么时候可能推翻它**：预计不会被推翻。**"几乎不用推翻"的决策通常说明选对了**（原答"当我 Python 水平比较高的时候"—— 水平高低不是推翻信号）。

### 3. 为什么阶段 1–3 不用 LangGraph，先手写循环

- **决策**：先手写循环，提前发现问题。
